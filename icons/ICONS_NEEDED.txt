X Account Filter - Icons Required
==================================

The extension requires PNG icon files at the following paths:

  icons/icon16.png   — 16x16 px  (toolbar / favicon size)
  icons/icon32.png   — 32x32 px  (Windows taskbar)
  icons/icon48.png   — 48x48 px  (Extensions management page)
  icons/icon128.png  — 128x128 px (Chrome Web Store / install dialog)

Recommended design:
  - Background: #15202b (X dark-theme blue-black)
  - Foreground: a robot or shield icon in #1d9bf0 (X blue)
  - Simple flat/outlined style matching X's design language

You can generate these icons using any image editor (Figma, Photoshop,
Inkscape, etc.) or an online icon generator such as:
  https://favicon.io/
  https://www.canva.com/
  https://realfavicongenerator.net/

For quick testing during development, a simple colored square PNG is
sufficient — the extension will load without icons but Chrome DevTools
will log warnings about missing files.
